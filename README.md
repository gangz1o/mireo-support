# 觅乐 Mireo — 技术支持 / Support

欢迎使用 **觅乐（Mireo）**，一款专为 iPhone、iPad 与 Mac 打造的原生无损音乐播放器。  
Welcome to **Mireo**, a native lossless music player crafted for iPhone, iPad, and Mac.

## 常见问题 / FAQ

### 支持的系统与设备 / Supported Platforms
- iOS 18.0+ / iPadOS 18.0+ / macOS 15.0+

### 支持的音乐来源 / Supported Music Sources
- **Apple Music**（需要有效的 Apple Music 订阅 / requires an active subscription）
- **本地音乐 / Local Music**（本机文件夹、文件 App、iCloud Drive）
- **NAS 与网络存储 / NAS & Network Storage**（SMB、WebDAV）
- **自托管音乐服务器 / Self-Hosted Servers**（Navidrome、Jellyfin、Emby、Plex、Funkwhale）

### 支持的音频格式 / Supported Audio Formats
FLAC, ALAC, WAV, AIFF, DSF / DSDIFF (DSD), APE, WavPack, Opus, Ogg Vorbis, AAC / M4A, MP3, CUE sheets.

### 恢复购买（觅乐 Pro）/ Restore Purchases (Mireo Pro)
觅乐 Pro 为一次性买断，绑定你的 Apple 账号，支持在 iPhone、iPad 与 Mac 之间共享。更换设备或重装 App 后，可在 App 内「觅乐 Pro」页面点击「恢复购买」。  
Mireo Pro is a one-time purchase linked to your Apple Account and works across iPhone, iPad, and Mac. After reinstalling or switching devices, open the Mireo Pro screen in the app and tap **Restore Purchases**.
